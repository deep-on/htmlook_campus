# excalidraw · Retrospective Board (rich)

A sprint retrospective board for **Kestrel · Sprint 27** (Team Falcon). Three
columns — **Went well**, **To improve**, **Action items** — each with three
sticky notes, plus a dot-vote legend. Action items carry an explicit owner.
27 elements, grouped per column header and per sticky so you can drag a note
or a whole column without losing its label.

Open `retro.excalidraw` in the Excalidraw pane to edit visually, add or move
sticky notes during the meeting, then export to SVG/PNG to paste into the
sprint summary. Each sticky is a grouped rectangle + label: drag the note and
its text moves with it.

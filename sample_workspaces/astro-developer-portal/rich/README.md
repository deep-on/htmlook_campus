# astro-starlight · Developer Portal (rich)

A Starlight developer portal for the fictional **Pylon** delivery platform — a
service for creating and tracking shipments via API. It includes an overview,
a five-minute quickstart, official JavaScript and Python SDK pages, and a REST
API reference. Every internal link (overview → quickstart → SDKs → reference)
resolves to a page that exists in this sample.

```bash
npm install
npm run dev      # http://localhost:4321
```

Pages live under `src/content/docs/`; the sidebar is configured in
`astro.config.mjs`. API keys, base URLs, and code samples are illustrative.

# Excalidraw · Pre-mortem Workshop (rich)

A launch pre-mortem for **Vela Insights** (a B2B analytics product). The team
imagines the launch already failed and works backwards from failure to cause
to mitigation.

## Files

- `diagrams/pre-mortem-board.excalidraw` — central prompt *"It's Q4. The launch
  failed. Why?"* with five failure hypotheses (onboarding, pricing, query
  latency, design partners, data import), each paired with a green mitigation
  card and a named owner. 33 elements.
- `diagrams/risk-matrix.excalidraw` — a likelihood × impact matrix that plots
  the same five risks as dots so the team can decide what to address first.
  15 elements.
- `WORKSHOP_GUIDE.md` — the 90-minute facilitation script.

Open either `.excalidraw` in the Excalidraw pane to run the workshop live, then
export to SVG/PNG for the launch readiness doc. Each risk + mitigation pair is
grouped, so dragging a risk keeps its mitigation and owner attached.

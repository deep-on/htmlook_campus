# Quarto · Phase 3 Clinical Trial Report

A fictional oncology Phase 3 efficacy/safety report for the investigational
agent EFFECT (EFFECT-3 trial, n=250). CONSORT flow + Kaplan-Meier survival +
safety tables.

## Seed content
- `index.qmd` — 8 sections (IMRAD variant + safety + appendix)
- `data/efficacy.csv` — n=250 synthetic patients
- `data/safety.csv` — CTCAE grading

## All data is fictional
The drug, trial, patients, and results are invented for demonstration. Nothing
here is a real clinical figure.

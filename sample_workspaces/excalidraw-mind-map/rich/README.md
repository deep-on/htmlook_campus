# excalidraw · Mind Map (rich)

A product-planning mind map for **Orbit v3** — a central node with five
branches (Onboarding, Mobile app, Integrations, Pricing, Performance), each
with sub-items and a connecting arrow. 22 elements, grouped per branch.

Open `mindmap.excalidraw` in the Excalidraw pane to edit visually, or export
to SVG/PNG. Drag a branch and its label/items move together (grouped).

A patch release that fixes a single, high-impact bug. No new features and no
breaking changes. Back to the [changelog index](/).

## Fixes

- `fix` **Cohort charts honored the wrong timezone.** Cohorts were bucketed in
  UTC regardless of the workspace timezone, so a "Day 0" cohort could include or
  exclude users near midnight incorrectly. Cohorts now bucket in the workspace
  timezone, matching every other chart. Existing cohort reports recompute
  automatically the next time they're opened.
- `fix` Tooltip values on stacked area charts rounded to the wrong precision.

## Upgrade notes

This is a drop-in patch over 2.7.0 — no action required. If you're on this
version and ready for new features, the next release is
[v2.8.0](/releases/v2-8-0/) (scheduled reports), followed by the major
[v3.0.0](/releases/v3-0-0/).

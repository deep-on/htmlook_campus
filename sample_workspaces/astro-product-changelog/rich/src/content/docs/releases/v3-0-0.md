The largest Tideline release to date. Funnels are rebuilt on a new column-store
query engine that makes most dashboards noticeably faster, and we've cleaned up
a long-standing inconsistency in saved-report URLs. Back to the
[changelog index](/).

## Highlights

`+` **added — Funnels v2.** Define a funnel with up to twelve steps, optional
per-step filters, and a configurable conversion window. Funnels now compute
incrementally, so a 30-day funnel over millions of events returns in seconds
rather than timing out.

`+` **added — Breakdown by any property.** Split any chart by a user or event
property (plan, country, referral source) directly from the chart toolbar.

`~` **changed — New query engine.** Aggregations run on a column store. Typical
dashboards load 3–5× faster; very large workspaces see more. No query syntax
changes — this is transparent to existing reports.

## Breaking changes

`!` **Saved-report URLs changed format.** Old links like
`/r?id=1842` now resolve to `/reports/1842`. Existing links are redirected for
90 days, but **update any bookmarks or embedded links** before that window
closes. Reports themselves are untouched; only the URL shape changed.

**Action required (self-hosted only):** run `tideline migrate report-urls` once
after upgrading to backfill redirect entries.

## Fixes

- `fix` Funnel step ordering no longer resets when you rename a step.
- `fix` CSV export now escapes commas inside text properties.

Upgrading from 2.x? Read the breaking change above first, then continue with
[v2.8.0](/releases/v2-8-0/) if you're skipping releases.

A feature release focused on getting Tideline insights to people who don't open
the dashboard every day. Back to the [changelog index](/).

## Highlights

`+` **added — Scheduled email reports.** Pick any saved report, choose a cadence
(daily, weekly, or monthly), and Tideline emails a rendered snapshot to a list
of recipients. Recipients don't need a Tideline seat to receive the email.

`+` **added — Slack delivery.** The same schedules can post to a Slack channel
instead of (or in addition to) email. Configure under Settings → Integrations.

`~` **changed — Faster events table.** The raw events explorer now paginates on
the server and streams rows as they arrive, so the first page renders almost
immediately even on high-volume workspaces.

## Fixes

- `fix` Date-range picker no longer jumps to the wrong month when the workspace
  timezone is west of UTC.
- `fix` Empty dashboards now show an onboarding hint instead of a blank panel.

This release contains no breaking changes — it's safe to upgrade directly from
[v2.7.1](/releases/v2-7-1/). The next release,
[v3.0.0](/releases/v3-0-0/), does include a breaking change, so read its notes
before jumping there.

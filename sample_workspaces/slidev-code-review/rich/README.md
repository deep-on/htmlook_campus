# slidev · Code Review Walkthrough (rich)

An onboarding talk from the fictional **Meridian Labs / Compass** team on how
they run code review: why review at all, the PR lifecycle, the reviewer
checklist, good-vs-nitpick comments, severity tags, tooling, PR size, and the
metrics they track (and deliberately don't).

A reusable template for any team that wants to write down its review culture.
Edit `slides.md`, then preview with the Slidev pane (md ↔ live HMR).

```bash
npx slidev slides.md
```

Swap in your own team's checklist and severity tags — the structure carries over.

# quarto · Course Syllabus (rich)

A complete university course syllabus — YAML front matter, a table of
contents, course description and learning outcomes, a full 16-week schedule
table, a weighted grading breakdown, and course policies (late work,
collaboration, generative AI, accessibility). The example course is
*DATA 5310 · Introduction to Data Engineering*.

Preview / render:

```bash
quarto preview index.qmd   # live
quarto render  index.qmd   # → index.html
```

Swap in your own course. The structure — description → outcomes → weekly
schedule table → grading table → policies → office hours — is the template.

# astro-starlight · Design System Docs (rich)

A Starlight documentation site for the fictional **Lattice** design system. It
covers foundations (color tokens, typography), components (button, input), and
a composed pattern (forms). The forms pattern cites the components and
foundations it builds on, and every internal link resolves to a page in this
sample.

```bash
npm install
npm run dev      # http://localhost:4321
```

Pages live under `src/content/docs/`; the sidebar is configured in
`astro.config.mjs`. Tokens and CSS class names are illustrative.

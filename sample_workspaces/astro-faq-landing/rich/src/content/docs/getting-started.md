Welcome to Bramble. This three-minute guide gets you from empty workspace to a
synced, organized notebook.

## 1. Create your first note

Press **N** (or the **+** button) anywhere. Start typing — there's no "save"
button; everything is saved as you go. The first line becomes the note title.

## 2. Organize with folders and tags

- **Folders** live in the left sidebar — drag a note onto one to file it.
- **Tags** are inline: type `#idea` or `#todo` anywhere in a note. Click a tag
  to see every note that uses it.

Most people start with folders and reach for tags once they have a few hundred
notes.

## 3. Sync across devices

Sign in with the same account on the web app and the mobile app. Notes sync
automatically — edits made offline upload the moment you reconnect. If anything
looks out of date, see the [syncing FAQ](/#syncing).

## 4. Next steps

- Invite teammates: Settings → Members (Team plan).
- Connect Slack or Zapier: Settings → Integrations.
- Questions about plans or privacy? Check the [FAQ](/).

Happy note-taking.

# astro-starlight · FAQ + Getting Started (rich)

A two-page Starlight help site for the fictional **Bramble** notes app: a
sectioned FAQ landing (Account / Billing / Syncing / Privacy / Troubleshooting)
with in-page jump links, plus a getting-started guide. Internal links between
the two pages are valid.

```bash
npm install
npm run dev      # http://localhost:4321
```

Edit the markdown under `src/content/docs/`; the sidebar is configured in
`astro.config.mjs`.

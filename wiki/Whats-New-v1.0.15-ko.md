# v1.0.15 에 들어온 것

릴리스: **2026-05-25** · 다운로드: [htmlook.app](https://htmlook.app)

> 다른 언어: [English](Whats-New-v1.0.15.md)

v1.0.15 는 **핫픽스** 입니다. 기능 셋은 v1.0.14 와 동일 — 4 개의 헤드라인
기능 (멀티 윈도우 탭, AI 허가 UX, 터미널 tmux 영속화, 마크다운 안전망) 은
[v1.0.14 에 들어온 것](Whats-New-v1.0.14-ko.md) 을 참조.

이 페이지는 v1.0.14 → v1.0.15 사이 24 시간 안의 변경만 다룹니다.

---

## 변경 사항

- **한글 이름 워크스페이스의 터미널 성능 fix.** v1.0.14 가 한글 이름
  워크스페이스를 열 때 발생하던 freeze 를 fix 했습니다. dogfooding 첫 날
  안에 그 fix 가 같은 영역에서 다른 문제를 허용한다는 게 드러났습니다 —
  여러 터미널 pane 을 열고 있으면 백그라운드 폴링이 누적되어 앱이
  굼떠지는 증상. v1.0.15 는 freeze fix 를 유지하면서 굼뜨는 증상을
  제거했습니다.

새 기능 없음. UI 변경 없음. 단축키 변경 없음.

---

## 업그레이드

- v1.0.14 → v1.0.15: HTMLook Pro 다음 실행 시 auto-updater 가 가져옵니다.
- v1.0.13 → v1.0.15: [v1.0.14 페이지](Whats-New-v1.0.14-ko.md) 를 먼저
  읽어서 주요 변경을 확인한 다음, 이 페이지로 돌아와 핫픽스 노트를
  확인하세요.
- 새로 설치: [htmlook.app](https://htmlook.app) 에서 다운로드.

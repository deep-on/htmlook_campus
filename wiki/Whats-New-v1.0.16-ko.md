# v1.0.16 에 들어온 것

릴리스: **2026-05-26** · 다운로드: [htmlook.app](https://htmlook.app)

> 다른 언어: [English](Whats-New-v1.0.16.md)

v1.0.16 는 창 닫기 동작을 끝에서 끝까지 정리하고, tmux 터미널의
드래그 선택을 패널 밖에서도 부드럽게 만들고, PPTX 변환 체인을
안정화합니다. 그리고 dogfooding 중 거슬리던 일상 paper-cut 들을
한 번에 묶어 정리.

---

## Highlights

### 1. 창 닫기, 한 번에 깔끔하게

신호등 ❌ 든, 탭 × 든, 단일 창이든, 여러 창 모드의 마지막 창이든,
모든 닫기 길이 같은 **Quit HTMLook Pro?** 확인을 거칩니다.
닫히는 동안 작은 진행 표시가 떠 있어서 닫는 중인지, 멈춘 건지가
명확합니다.

- **저장 안 된 변경사항 보호.** 닫는 창의 어떤 탭이라도 저장
  안 된 변경사항이 있으면 Quit 다이얼로그 전에 한 번 더 묻습니다.
  취소하면 앱과 모든 작업이 그대로 돌아옵니다.
- **탭 × 가 탭 단위.** 탭이 두 개 이상일 때는 그 탭만 닫습니다
  (저장 안 된 파일은 동일하게 확인). 탭이 하나일 때는 신호등
  ❌ 와 동일 — 앱 종료 확인.
- **탭 스트립 동기화.** 여러 창 모드에서 한 창을 닫으면, 다른
  창들의 탭 스트립에서 그 탭이 사라지는 애니메이션이 창이
  사라지는 시점과 함께 진행됩니다. 더 이상 유령 탭이 남지
  않습니다.
- **닫는 중 같은 워크스페이스 다시 열기 안전.** 닫는 중인
  워크스페이스를 다시 클릭하면 HTMLook Pro 가 정리가 끝날
  때까지 기다린 다음 깨끗하게 다시 엽니다.

### 2. tmux 터미널 — 드래그 선택이 패널 밖까지

tmux 터미널에서 드래그하다가 커서가 패널 바닥을 넘어가도
화면이 계속 스크롤되면서 선택이 따라옵니다. **vim**, **less**,
**htop** 같은 alternate-buffer 앱에서도 작동 — 셸 출력에만
국한되지 않습니다.

휠과 드래그가 서로 부딪히지 않습니다: 최근 5초 안에 휠로
스크롤했다면 다음 드래그는 현재 보이는 위치에서 이어집니다.

### 3. tmux 잔존 세션 정리

세션 재시작이나 크래시 이후 `tmux ls` 를 깨끗하게 유지하는 세
가지 방법:

- **터미널 팝오버의 Kill 버튼** — 가리킨 세션 하나를 직접
  정리.
- **Settings → Terminal → Auto-sweep orphans** (기본 OFF) —
  HTMLook Pro 시작 시 임계치 이상 idle 인 세션을 자동 정리.
- **`htmlook --tmux-cleanup`** CLI — 앱 밖에서 같은 sweep
  실행. 스크립트에 유용.

### 4. PPTX 변환, Cancel 까지

변환 체인이 **PowerPoint → LibreOffice** 순으로 정리됐습니다.
Keynote 는 한글 폰트 어긋남이 반복되고 AutoRecover 다이얼로그가
중간에 떠서 제거. PowerPoint 는 **백그라운드에서 조용히 실행**
되어 작업 흐름을 가리지 않습니다.

변환이 **30초** 넘게 걸리면 로딩 카드에 **Cancel** 버튼이
나타나 언제든 빠져나올 수 있습니다.

### 5. 일상 polish

- **사이드바 Name 열 길이를 직접 조절.** 컬럼 헤더의 핸들을
  드래그, 또는 *Settings → Sidebar → Name column width* 입력.
  Name 정렬 버튼을 **길게 누르면** 현재 사이드바 폭에 자동
  맞춤.
- **Sort · Zoom 버튼의 커스텀 툴팁** 이 **버튼 위쪽**으로
  떠서 가려지지 않고, 미니멀한 pill 스타일.
- **새 탭 / 새 창 흰 깜빡임 제거** — 다크 / 라이트 둘 다 첫
  paint 부터 테마가 적용됩니다.
- **autoSave OFF 가 실제로 OFF.** OFF 로 두면 저장이 일어나지
  않습니다 (이전엔 1.5 초 타이머가 계속 돌았음).
- **Pasted 탭 토글.** 텍스트 필드 밖에서 붙여넣기하면 기본은
  새 Pasted 탭. 끄려면 *Settings → Editor* 에서.
- **탭 순서 안정.** 새 탭은 항상 가장 오른쪽. 워크스페이스
  열기 (한글 이름 포함) 가 기존 탭 순서를 흐트리지 않습니다.
- **터미널 forward-delete** — `⌘⌫` (줄 처음까지) 와 `⌥⌫`
  (단어 단위) 가 셸에 전달됩니다.
- **드래그-선택이 클립보드로.** 터미널 드래그-선택이 자동으로
  시스템 클립보드에.
- **워크스페이스 빠른 복귀.** 여러 터미널 패인이 있는
  워크스페이스를 열면 활성 탭이 먼저 살아나고 나머지는 보일
  때 따라옵니다.

### 6. 워크스페이스 청소

- **오피스 / 페이지스 / LibreOffice 의 잔존 잠금 파일** (`~$file.docx`
  등) 이 워크스페이스를 열 때 `.htmlook/lock-quarantine/`
  으로 격리됩니다 (Settings 에서 끌 수 있음).
- **`htmlook_apply_edit` 백업 파일** 이
  `.htmlook/file-backup/` 으로 이동해 사이드바를 어지럽히지
  않습니다.
- **한글 폴더 / 파일 이름** 이 사이드바, 검색, 탭 순서에서
  일관되게 일치.
